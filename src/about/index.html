About this starter

This page exists for a specific reason: it is nested one level deep. If asset paths, partials or the active navigation state were going to break anywhere, they would break here.

{{picture src="workspace.jpg" alt="Abstract warm gradient used as a placeholder photograph" sizes="(min-width: 60rem) 60rem, 100vw" class="prose__figure" }}

How it is meant to be used

Clone it, delete the demo sections, keep the plumbing. The parts worth keeping are the build config, the SCSS architecture, the image pipeline and the accessibility utilities — everything else on this page is example content.

What is deliberately missing

No TypeScript, no test runner, no component generator, no CI. Each of those is a cost you pay forever, and none of them earn their place on a typical marketing site. Add them to a project when that project actually needs them.
