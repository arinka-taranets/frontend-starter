What you get

  • Pages, not boilerplate

    Every .html file under src/ becomes a page automatically. Shared markup lives in partials, so a nav change is one edit.

  • Images handled for you

    Drop a file into src/assets/images/. AVIF, WebP and a fallback are generated at every breakpoint, with width and height set to prevent layout shift.

  • Accessible by default

    Skip link, visible focus rings, real landmarks, aria-current on the active page and a keyboard-operable mobile menu — present from the first commit.
